# 123-web | Cloud Drive & Semantic Storage Manager

[![Deploy to GitHub Pages](https://github.com/awasthisach/123-web/actions/workflows/deploy.yml/badge.svg)](https://github.com/awasthisach/123-web/actions/workflows/deploy.yml)

A web application for cloud drive management, AI semantic file search, folder relocation, phone storage/SD card scanning, and client-side AES-256 privacy vault.

## Live Deployment
- **GitHub Pages**: [https://awasthisach.github.io/123-web/](https://awasthisach.github.io/123-web/)
- **AI Studio Preview**: [https://ais-pre-y3xuzxdnayshpet3dy7dlt-608230001000.asia-southeast1.run.app](https://ais-pre-y3xuzxdnayshpet3dy7dlt-608230001000.asia-southeast1.run.app)

## Core Capabilities
- **Google Drive Integration**: Client-side OAuth authentication, live synchronization of Drive files and folders, bulk moving, and deletion.
- **AI Semantic Search**: Concept and context-based vector search with instant file preview and direct folder moving.
- **Device & SD Card Scanner**: Scan simulated and real device memory, backup files to Drive or secure vault.
- **AES-256 Privacy Vault**: Client-side encrypted container for confidential contracts, documents, and credentials.
- **CI/CD Pipeline**: Automated static build and deployment via GitHub Actions (`deploy.yml`).

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
